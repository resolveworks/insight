# Collections

Use collections to organize documents by investigation, beat, or source.

## Scanned documents

Insight extracts the text already embedded in PDFs. Scanned pages without embedded text can be stored and shared, but their contents will not be searchable; Insight does not currently perform OCR.

## Sharing and access

Sharing a collection generates a ticket. Anyone with that ticket can access the collection, so treat it like a password.

Peers exchange documents and extracted text directly, without a central document server. Recipients get full copies that work offline; search indexes and conversations remain local. Peers must be able to connect to exchange data.

Access cannot be revoked. A recipient keeps any data already received and may continue syncing with other peers. Share sensitive collections only with people you trust, and create a new collection if you need to restrict future access.
